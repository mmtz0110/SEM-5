# NusaEvent Hub

Aplikasi Flutter Material 3 untuk Nusa Tech Fest. Aplikasi ini menyediakan:

- daftar seminar dan workshop dengan filter kategori AI, Mobile, IoT, dan Cybersecurity;
- galeri poster dan denah venue yang dapat digeser serta diperbesar;
- formulir pendaftaran tervalidasi untuk nama, NIM, email, dan WhatsApp;
- tiket terdaftar dengan pembatalan melalui swipe dan dialog konfirmasi.
